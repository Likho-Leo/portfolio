# Likho Leohla — Portfolio

Personal portfolio website built with React, showcasing my work as an Information Technology graduate specialising in backend development and system design.


---

## About

This portfolio highlights my academic projects, certifications, and technical skills. It was designed to reflect my focus on building reliable, data-driven software using C#, ASP.NET Core, and SQL Server.

---

## Built With

- **React**
- **Lucide React** — icons
- **CSS** — custom styling, no UI framework
- Google Fonts — Syne & DM Sans

---

## Features

- Responsive layout for desktop and mobile
- Skills section with proficiency indicators
- Project cards linking to GitHub repos and demo videos
- Qualifications and certifications sidebar
- Contact section
